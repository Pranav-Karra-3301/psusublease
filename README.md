# PSU Leases (deprecated)

> **This project is deprecated and no longer maintained.** The site at psuleases.com is not actively running, and the code here is kept only for reference. Please do not treat it as a live service.

PSU Leases was a marketplace for Penn State students to find and post leases, subleases, and relets around State College. Students could browse available listings, post their own, and search by area, budget, and dates.

## Stack (for reference)

Next.js 15 (App Router), Supabase for auth and data, Tailwind CSS, and Framer Motion.

Because the backend services behind this app have been wound down, running it locally will not produce a working experience without standing up your own Supabase project and configuration.
